# Вердикт — сервер экспертной оценки

Полноценный сервер: эксперты со своих телефонов/планшетов/ноутбуков заходят
по ссылке и ставят оценки, модератор в реальном времени видит таблицу,
может распечатать и скачать стандартный `.xlsx`. Файл `data/Оценки.xlsx`
на диске сервера обновляется автоматически после каждой оценки — это
и есть постоянная резервная копия.

## Шаг 1. Установить Node.js (один раз на компьютер)

Скачать и установить с https://nodejs.org (версия LTS, "для большинства
пользователей"). Проверить, что встало: в терминале/командной строке
набрать `node -v` — должна показаться версия 18 или выше.

## Шаг 2. Установить зависимости проекта (один раз)

Открыть терминал/командную строку в этой папке и выполнить:

```
npm install
```

(или просто дважды кликнуть `start.bat` на Windows / `start.sh` на Mac —
они сами поставят зависимости при первом запуске).

## Шаг 3. Запустить сервер

```
npm start
```

или дважды кликнуть `start.bat` / `start.sh`.

В терминале появится:

```
Открыть на этом компьютере:      http://localhost:3000
В локальной сети доступен по:    http://192.168.х.х:3000
```

Откройте `http://localhost:3000` в браузере на компьютере модератора —
и вы увидите выбор роли "Я эксперт" / "Я модератор".

## Шаг 4. Дать доступ экспертам через интернет (не по локальной сети)

Пока сервер запущен (окно терминала не закрывайте), откройте **второе**
окно терминала в этой же папке и выполните:

```
npm run tunnel
```

Появится публичная ссылка вида `https://смешное-слово.loca.lt` — её и
раздайте экспертам (по SMS, в чат, QR-кодом). Она работает, пока запущены
оба окна терминала и включён компьютер модератора. Подходит для разового
мероприятия.

### Более надёжный вариант — постоянный сервер в облаке

Если оценивание проходит регулярно и нужна ссылка, которая работает
всегда (не завися от компьютера модератора), этот же проект можно
задеплоить на бесплатный тариф Render.com или Railway.app — тогда сервер
будет доступен 24/7 по постоянному адресу. Это отдельный шаг (нужен
аккаунт на хостинге и загрузка туда этой папки) — скажите, если он нужен,
подготовлю пошаговую инструкцию под конкретный сервис.

## Пароль модератора

По умолчанию пароль: `вердикт2026`. **Обязательно смените его** перед
реальным мероприятием:

- **Локальный запуск:** `set MODERATOR_PASSWORD=ваш_пароль && npm start`
  (Windows) или `MODERATOR_PASSWORD=ваш_пароль npm start` (Mac/Linux).
- **На Render:** в панели сервиса → Environment → Add Environment Variable
  → ключ `MODERATOR_PASSWORD`, значение — ваш пароль → Save (сервис сам
  перезапустится).

Пароль экспертам не нужен и не запрашивается — устройство эксперта один
раз закрепляется за конкретным экспертом (без поля «имя») и дальше не
даёт выйти из этой роли. Если нужно переназначить устройство на другого
эксперта, внизу его экрана есть мелкая ссылка «Технический доступ» —
она требует тот же пароль модератора.

## Импорт списка участников

В экране модератора появился блок «Участники». Туда можно:

- **Импортировать файлом** — .xlsx или .docx (с таблицей внутри). Столбцы
  строго в порядке: **Имя, Возраст, Мероприятие/номинация**. Первая
  строка может быть заголовком («Имя», «Возраст», …) — сервер сам её
  определит и пропустит, либо сразу данными.
- **Добавить вручную** — по одному, через форму.
- Редактировать (✎) или удалить (🗑) любого участника прямо из таблицы.

Каждый эксперт на своём устройстве видит крупную карточку текущего
участника и листает список кнопками «← Предыдущий» / «Следующий →» —
это личная навигация каждого эксперта, она не завязана на остальных.
Если у эксперта есть незаполненная оценка, система переспросит перед
переходом дальше.

## Печать результатов

- «🖨 Печать всей таблицы» на экране модератора — печатает сводную
  таблицу целиком.
- В блоке «Результаты по участникам» у каждого участника есть своя
  кнопка «🖨 Печать» — печатается ведомость только по этому участнику
  (жюри × критерии, сумма, комментарии).

## Данные

- `data/store.json` — все настройки и оценки (переживает перезапуск сервера).
- `data/Оценки.xlsx` — тот же самый стандартный Excel-файл, обновляется
  автоматически. Модератор также может в любой момент нажать «Скачать
  Excel» прямо в браузере.

## Если что-то пошло не так

- Порт 3000 занят другой программой → задайте другой порт:
  `PORT=4000 npm start` (Mac/Linux) или `set PORT=4000 && npm start`
  (Windows).
- Эксперты не видят страницу через `npm run tunnel` → проверьте, что
  окно с `npm start` всё ещё открыто и компьютер не ушёл в спящий режим.
